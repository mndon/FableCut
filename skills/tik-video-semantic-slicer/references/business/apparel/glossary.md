# 服装直播带货（垂类领域包）

本文件是「业务知识」中的垂类领域包，承载服装直播带货这一品类的专用知识：服装面料术语标准库 + 字幕领域纠错原则。

本技能当前主要用于剪辑衣服电商直播，会大量出现服装材质、工艺、版型等专有名词；语音转写（ASR）对这些词极易误识（同音 / 近音），需在烧字幕前纠正，使烧进画面的字幕术语正确。

## 一、纠错原则（铁律）

- 只依据本库纠正：转写词不在本库且上下文合理，不改（避免臆造错误）。
- 只改明显误识：仅当某词音近 / 形近本库某术语、且上下文指向该术语时纠正。
- 不动时间轴：只在 edit_config.json 的 subtitle_text 中记录 text 更正，绝不改 ASR 原文或时间轴；字幕时间取自工程片段（见 [pipeline-io.md](../../tools/pipeline-io.md)）。
- 不润色不重组句法；拿不准不改，提请用户确认。
- 别名 / 等价词不纠：本库列出的合法中文别名、营销名（黑话组除外）均保留原样。
- 不触碰 content-constraints.md 红线（禁词 / 价格 / 口误等），不替代阶段三筛选。
