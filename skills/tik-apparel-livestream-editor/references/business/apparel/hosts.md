# 主播剪辑档案（按品牌归类，服装品类）

记录服装品类下各品牌个性化剪辑要求，供准备阶段读取预填。品类通用策略见同目录 content-strategy.md / content-constraints.md，本文件只记各品牌相对通用策略的个性化差异。匹配顺序：阶段一优先按品牌名命中品牌章节（请求点名的品牌 / 素材文件名或路径出现的品牌名）；仅当未提到任何品牌时，才按主播名映射到其所属品牌章节。品牌章节标题中括号及斜杠分隔的写法均为同一品牌的别名（如「麻享（麻STUDIO）」「麦麦秋（CONNAITRE）/ 壹秋童装」），素材文件名、路径或请求里出现任一别名即视为命中该品牌。按品牌名与主播名均未命中的，本文件不提供要求，直接采用品类通用策略（定义见同目录 content-strategy.md / content-constraints.md）。

要求挂在品牌下，同品牌主播默认共享品牌要求；个别主播如需不同于品牌默认，在品牌下以「主播级覆盖」小节单独列出（未列出的项继承品牌默认）。主播的「红线与禁忌」是叠加在 content-constraints.md 品类通用禁词清单之上的补充项，不自替换通用规则：命中品牌或主播时，通用禁词清单照常适用，本文件所列禁项额外叠加上去一起查。

识别到主播但无品牌归属、或连主播都未识别到，这两种情形本文件都不提供要求，直接采用品类通用策略（定义见同目录 content-strategy.md / content-constraints.md）。不同品类的主播档案分目录存放，本文件仅覆盖服装品类。
